# CLAUDE.md

Self-use German vocabulary flashcard SPA. Vue 3 + Vite, no backend, deployed to GitHub Pages.
User-facing overview, stack, and the data-update pipeline are in [README](ReadMe.md) — this file is the internal map.

## Commands

```bash
npm run dev       # local dev server (http://localhost:5173/DE-Vokabeln/)
npm run build     # production build to dist/
npm run deploy    # manual publish to gh-pages branch (fallback; push to main auto-deploys)
python build.py   # regenerate public/data/*.json from notes — see README "Update vocabulary data"
```

## Frontend layout

- `src/router/index.js` — hash history, base `/DE-Vokabeln/` (matches `vite.config.js` `base`). Routes: `/`, `/study/:mode` (`view` | `quiz`), `/review`, `/saetze`, `/stats`, `/data`; anything else redirects to `/`.
- `src/views/Home.vue` — four buttons: Ansehen (`/study/view`), Quiz (`/study/quiz`), Sätze (`/saetze`), Review (count); top-left icon links to `/stats` (bar chart) and `/data` (gear).
- `src/views/Study.vue` — one card at a time from all decks merged. Picks a group from `deckGroups` uniformly, then a card within it by familiarity. Quiz mode shows multiple-choice (distractors from the card's own deck); view mode just flips.
- `src/views/Review.vue` — wrong-card queue; first choose Ansehen or Quiz. Ansehen: flip through once in order, no score / wrong-list changes. Quiz: wrong → back of queue (score `-2` only on the first miss per session), right → removed. "Ausblenden" hides the card for good (5 s undo).
- `src/views/Saetze.vue` — one random sentence from `sentences.json` (never the same twice in a row), German + translation shown at once. No scores or stats.
- `src/views/Stats.vue` — stacked bar chart (green correct / red wrong / grey viewed) over a continuous day axis; 1W / 1M / Alle zoom.
- `src/views/Data.vue` — clears localStorage per category (familiarity / wrong list / daily stats / hidden) or all at once; each util owns a `clear*`/`reset*` export. Also lists hidden cards with per-word restore.
- `src/components/VocabCard.vue` — renders a card; branches on `deck` for per-type fields. Person cards show one meaning line under both gender blocks: `getMeaning` joins `意思男` / `意思女` with `, ` and drops duplicates.
- `src/utils/` — `wrongCards.js` (wrong list + `getCardKey` + choice generation), `stats.js` (daily bar data), `cardScores.js` (familiarity weighting), `hiddenCards.js` (hidden list), `decks.js` (`loadDeck` — cached json fetch per deckId).

`deckId` values: `nomen_obj`, `nomen_people`, `verben_base`, `adj_adv`, `phrasen` (see `src/constants.js`); each is exactly `public/data/<deckId>.json`.
`deckGroups` (constants.js) sets the pick groups: Nomen (`nomen_obj` + `nomen_people`), `verben_base`, `adj_adv`, `phrasen`.

## Vocabulary data — `public/data/*.json`

Generated by `build.py`; **do not hand-edit** except `例句` / `翻译` (those are safe to fix by hand).
Array of objects with Chinese key names, varying by file:

| file | key fields | shared |
|---|---|---|
| `nomen_obj` | `单数` `复数` `意思` | every entry also has `例句` `翻译` |
| `nomen_people` | `单数男` `复数男` `意思男` `单数女` `复数女` `意思女` | |
| `verben_base` | `原型` `现在` `过去` `完成` `意思` | |
| `adj_adv` | `原型` `比较级` `最高级` `意思` | |
| `phrasen` | `词组` `意思` | |

Two Excel input formats feed the same json shape (`build.py` picks per notes folder):
- **A-level** (`_A1`, `_A2`): `Nomen.xlsx` / `Verben.xlsx` / `Adjektive.xlsx`, columns map 1:1 to json fields (`A_TEMPLATES`).
- **DW** (B1+, folder has `Vokabeln.xlsx`): sheets `Nomen` / `Personen` / `Verben` / `Adjektive` / `Phrasen`; cells parsed by `dw_parse.py` (`DW_TEMPLATES`).
  Nouns `Gegenteil, -e (n.)` → `das Gegenteil` / `die Gegenteile` (plural expanded; unexpandable kept raw + warned; `(…, meist Singular)` note appended to 复数).
  Verbs: `jemand*` / `etwas` dropped, verb first like A-level: `jemanden aus|bilden` → `bilden aus`, `sich aus|ruhen` → `ruhen sich aus`.
  Persons: single `意思` goes to `意思男` (or `意思女` when there is no male form).
  Adjectives: `比较级` / `最高级` left empty.
B1 and A-level entries share keys (`DECKS_META.key_fields`), so a B1 word already in A-level is skipped, not duplicated.

`sentences.json` — `[{ 例句, 翻译 }]`, every line of each `NOTES_DIRS/sentences.docx` (append-only, dedup by `例句`).
It is the priority corpus for word examples: a word matched from it gets that sentence's `翻译` copied too, so only OpenSubtitles sentences go to Ollama.
Translations are copied, not linked — hand-fixing a `翻译` in `sentences.json` does not update word entries that already use the sentence.

## localStorage (all client-side, per device)

| key | shape | written by |
|---|---|---|
| `dailyStats` | `[{ date, correct, wrong, view }]` — only days with activity; gaps filled at read time by `dailySeries()` | `stats.js` |
| `wrongCards` | `[{ deck, data }]` | `wrongCards.js` |
| `cardScores` | `{ "<deck>\|<word>": level }` — familiarity 0..5, key from `getCardKey` | `cardScores.js` |
| `hiddenCards` | `["<deck>\|<word>"]` — never picked in Study / Review; still usable as distractors | `hiddenCards.js` |

Familiarity weighting: `pickWeightedIndex` (takes `[{ deck, data }]`) picks cards with weight `1/(level+1)` (level 5 ≈ 1/6 of a new card, never 0).
Quiz answer: correct `+1`, wrong `-2`. Non-quiz view: `+0.34`. Old `dailyStats` entries without `view` read as 0.

## Deploy

Push to `main` → `.github/workflows/deploy.yml` builds and publishes to Pages.
One-time repo setting: Settings → Pages → Source → GitHub Actions.

`_A1` / `_A2` / `_B1…` (notes: xlsx + docx), `resource/` (corpora), `*.docx` `*.xlsx` — see `.gitignore`.
On another machine these are absent; `public/data/*.json` is the committed source of truth for the app.
